# E2E Testing Skill

## Purpose
Create and maintain critical Playwright flows.

## Required flows
1. Browse product → detail → cart
2. Checkout → order created
3. Admin updates product
4. Inventory adjustment
5. Custom request submission

## Rules
- Prefer stable role/label/test-id selectors.
- Avoid sleeps when a deterministic wait is available.
- Seed known data.
- Keep critical smoke tests small.

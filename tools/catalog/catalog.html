📊 Biểu đồ Dung lượng & Phân tích nội dung ZIP (D:\data3D)

🧬 Dấu vân tay & Kiểm tra trùng trước khi thêm (SQLite Index)

1️⃣ Check thư mục sắp thêm vào kho (không làm thay đổi file)

2️⃣ File trùng nội dung SHA-256 100% đang nằm sẵn trong D:\data3D

Bấm "Quét file trùng trong D:\data3D" để kiểm tra trùng chính xác theo mã SHA-256 (kể cả khi 2 file khác tên nhau).
